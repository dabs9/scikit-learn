### F1 — Truncated X vs. full-length labels_ crashes `_weighted_cluster_center` on non-finite data
severity: medium
evidence: sklearn/cluster/_hdbscan/hdbscan.py:733 (`X = X[finite_index]` — X shrinks to shape `(n_finite, n_features)`), sklearn/cluster/_hdbscan/hdbscan.py:840-844 (`new_labels = np.empty(self._raw_data.shape[0], ...)`; `self.labels_ = new_labels` — now shape `(n_raw,)` where `n_raw > n_finite`), sklearn/cluster/_hdbscan/hdbscan.py:854-855 (`if self.store_centers: self._weighted_cluster_center(X)` — passes the truncated X), sklearn/cluster/_hdbscan/hdbscan.py:908-910 (`mask = self.labels_ == idx` produces a length-`n_raw` boolean; `data = X[mask]` indexes a length-`n_finite` array with it)
scenario: "User calls `HDBSCAN(store_centers='centroid').fit(X)` on a feature array containing any `np.inf`/`np.nan` row → non-finite branch strips X down to finite rows, then rebuilds `labels_` to `n_raw` length, then `_weighted_cluster_center(X)` runs `X[mask]` with a length-mismatched boolean mask and numpy raises `IndexError: boolean index did not match indexed array` — fit() aborts after having already mutated `self.labels_`, `self.probabilities_`, and `self._single_linkage_tree_`, leaving a partially-fit estimator"
contract: In `fit()` at line 855, pass `self._raw_data` (the pre-truncation array) to `_weighted_cluster_center` instead of the local truncated `X`, so the boolean masks derived from `self.labels_` line up with the row axis of the feature array; the outlier labels `-1/-2/-3` are already excluded by `range(n_clusters)`, so no non-finite rows are selected during centroid/medoid computation.
instances: single-instance
